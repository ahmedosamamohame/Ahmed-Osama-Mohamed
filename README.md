## 🚀 Featured projects

### 🎙️ [VOC AI (vocai)](https://github.com/ahmedosamamohame/vocai)
An LLM-powered **Voice of Customer** platform. Customers send feedback through a link or QR code, with no app download or account needed. Gemini then classifies each message, scores sentiment and priority, summarizes the problem, suggests an action, and drafts a reply.

- Every complaint becomes a **ticket** with a status and a tracking code
- Groups recurring problems by root cause
- **Ask Your Data**: a chat over your own feedback data, built with **RAG**
- Alerts on complaint spikes and weekly summary reports
- Data separation between businesses, and personal data protection before text is sent to the AI
- Arabic and English support with RTL, CSV import, and API integration
- **Stack:** Flutter · FastAPI · Python · Google Gemini · Embeddings · RAG · SQLAlchemy · Docker · GitHub Actions
